# AL-BARQ NET – Hotspot Simulator
### تطبيق محاكاة ومعاينة صفحات تسجيل دخول MikroTik Hotspot

تطبيق أندرويد مستقل ومتقدم يعمل على الهاتف دون الحاجة للاتصال براوتر MikroTik حقيقي. يتيح لمهندسي ومصممي الشبكات اختبار صفحات تسجيل الدخول (Hotspot)، فحص الأخطاء، محاكاة المتغيرات والمسارات، والتحقق من التجاوب مع أحجام الشاشات المختلفة بأمان تام ودون تعديل ملفات المصدر الأصلية.

---

## ⚡ المميزات الرئيسية

1. **اختيار المجلد عبر Storage Access Framework (SAF)**:
   - فتح مجلد الهوتسبوت الخاص بك مباشرة من ذاكرة الهاتف مع الحفاظ على سرية وسلامة الملفات الأصلية دون تغييرها.
   - يتوفر أيضاً نموذج تجريبي مدمج لشبكة البرق نت (`Built-in Demo`) للبدء الفوري بنقرة واحدة.

2. **محرك محاكاة MikroTik Hotspot (Template Engine)**:
   - استبدال تلقائي لمتغيرات MikroTik:
     - `$(link-login-only)` و `$(link-login)` و `$(link-orig)` و `$(link-status)` و `$(link-logout)` و `$(link-redirect)`.
     - `$(ip)` و `$(mac)` و `$(username)` و `$(hostname)` و `$(identity)` و `$(server-name)` و `$(interface-name)`.
     - `$(uptime)` و `$(session-time-left)` و `$(bytes-in)` و `$(bytes-out)` و `$(remain-bytes-total)` و `$(refresh-timeout)`.
     - `$(chap-id)` و `$(chap-challenge)`.
   - معالجة ذكية للشروط المتداخلة:
     - `$(if error) ... $(elif ...) ... $(else) ... $(endif)`
     - `$(if trial == 'yes')`
     - `$(if chap-id)`
     - `$(if session-time-left)`

3. **محاكاة المسارات والطلبات المحلية (Route Interceptor)**:
   - محاكاة استجابة المسار الخاص `GET /login?var=callBack` وإرجاع بيانات الجلسة وسكربت الاستدعاء.
   - محاكاة إرسال نماذج تسجيل الدخول `POST /login` أو `$(link-login-only)`.
   - محاكاة مسار الحالة `/status` ومسار تسجيل الخروج `/logout` ومسار الأخطاء `/error`.
   - تحميل الموارد النسبية (CSS, JS, الصور, الخطوط, الأيقونات).

4. **معاينة مرنة ومحاكاة الأجهزة (Responsive Preview)**:
   - أحجام شاشات متعددة: هاتف صغير (360dp)، هاتف قياسي (412dp)، هاتف كبير (480dp)، جهاز لوحي (768dp)، ملء الشاشة.
   - تبديل الاتجاه بين الوضع العمودي والأفقي (Portrait / Landscape).
   - التحكم بمستوى التكبير (Zoom 50% - 200%).
   - زر إعادة تحميل سريع وتحديث المعاينة.

5. **اختبار تسجيل الدخول والجلسات (Login Testing)**:
   - اختبار تسجيل الدخول ببيانات تجريبية.
   - خيار محاكاة نجاح الدخول (الانتقال لصفحة `status.html`).
   - خيار محاكاة فشل الدخول مع إظهار رسالة الخطأ المخصصة في `login.html`.
   - عرض معلومات الجلسة (IP, MAC, استهلاك البيانات, الوقت المتبقي).
   - اختبار تسجيل الخروج والعودة لصفحة الدخول.
   - فحص وتوضيح تشفير CHAP MD5 عبر `md5.js`.

6. **لوحة الفحص والتشخيص (Diagnostic Engine)**:
   - رصد أخطاء JavaScript وتحذيرات الكونسول مع أرقام الأسطر والملفات المصدرية.
   - رصد الموارد المفقودة وأخطاء `404 Not Found` (مثل الصور وملفات CSS والخطوط).
   - رصد المتغيرات التي بقيت دون استبدال `$(...)`.
   - فحص عناصر HTML المخفية بأساليب CSS (`visibility: hidden` و `display: none`).
   - تقديم اقتراحات عملية بالعربية لإصلاح كل مشكلة مرصودة.
   - إمكانية نسخ تقرير الفحص ومشاركته بنقرة واحدة.

7. **واجهة عربية احترافية بهوية البرق نت**:
   - دعم كامل لاتجاه اليمين إلى اليسار (RTL).
   - هوية بصرية تقنية مميزة بالأزرق الملكي والداكن ولمسات الصواعق الكهربائية السماوية والذهبية.

## 🛠️ التقنيات المستخدمة

- **لغة البرمجة**: Kotlin
- **واجهة المستخدم**: Jetpack Compose & Material 3
- **إدارة الحالة**: MVVM (ViewModel + StateFlow + collectAsStateWithLifecycle)
- **المعاينة والويب**: Android WebView + WebViewClient + WebChromeClient
- **إدارة التخزين**: Android Storage Access Framework (SAF) عبر `DocumentFile`
- **الاختبارات**: JUnit + Robolectric

## 🚀 كيفية البناء والتشغيل

1. **فتح المشروع في Android Studio**:
   - افتح المجلد في Android Studio (يُفضل إصدار Ladybug أو أحدث).
   - سيتولى Gradle مزامنة التبعيات تلقائياً.

2. **بناء المشروع عبر موجه الأوامر**:
   ```bash
   gradle assembleDebug
   ```

3. **تشغيل الاختبارات المحلية**:
   ```bash
   gradle :app:testDebugUnitTest
   ```
